# ATHENA

Este projeto está sendo desenvolvido como TCC no ano de 2026.

Estamos desenvolvendo um site para controle de estoque visando automatizar o acompanhamento e a compra dos produtos.

**Nosso objetivo é reduzir o desperdício e evitar a falta dos produtos em estoque.**

Tecnologias usadas até o momento:
- HTML;
- CSS;
- Bootstrap.

Próximos passos:

- Conexão ao banco de dados (em nuvem);
- Adição de inteligência artificial para compra de produtos;
- Integração com hardware (balança).
